# ReliefOS 2.0 — PayPal AI Hackathon

Collective emergency procurement: NGO requests become one optimized purchase, approved by a human,
paid with **PayPal Sandbox**, explored in **AG Grid**, and orchestrated by **AI agents over a real MCP server**.

All code, setup and the demo script are in [`ReliefOS/`](ReliefOS/README.md).
Architecture and trust boundaries: [`ReliefOS/server/docs/ARCHITECTURE.md`](ReliefOS/server/docs/ARCHITECTURE.md).
